## 1. 문제 정의

**대상** (가정, 친구 테스트로 확인할 것)
- 주 대상: AI 이야기는 매일 듣지만 어떻게 여기까지 왔는지는 모르는 20~30대. 폰으로 틈틈이 게임을 한다.
- 부 대상: 방치형 게임을 원래 좋아하는 사람.

**문제 인식**
- AI 역사는 공부하려면 딱딱하고, 방치형 게임은 숫자만 커져서 금방 질린다.

**원하는 것 / 기대하는 것**
- 출퇴근 5분씩 가볍게 켜서 성장하는 맛을 느끼고, 하다 보면 "아 이게 이렇게 된 거구나"를 알게 되는 것.

**관찰되는 현상** (지금까지 모은 것. 실제 플레이어 데이터는 아직 없음)
- 만든 사람이 직접 해 본 피드백(20차): "가시성이 떨어지고 뭐가 뭔지 모르겠다, 너무 복잡하다."
- 봇 플레이(12차): 시대 3에서 보스 11번 도전 11번 패배, 화면이 실패 알림으로 덮임.
- 자체 플레이 기준선(스프린트 1, 아래 5절).

**기대 효과 (지표)**
| 지표 | 무엇을 보나 | 어디서 보나 |
|---|---|---|
| M1 첫 세션 시대 3 도달 비율 | 처음 10~15분 안에 게임을 '이해'했는가 | 시대 3 타임어택 랭킹 참가자 수 ÷ 설치 수, 친구 테스트 관찰 |
| M2 다음 날 다시 켠 비율 (D1) | 다시 하고 싶은가 | Play Console 통계, 친구 테스트 설문 |
| M3 "헷갈렸다" 피드백 비율 | 복잡함 문제가 줄었는가 | 의견 보내기, 테스트 후 질문 |
| M4 엔딩 도달 비율 | 끝까지 재미가 이어지는가 | 시대 10 타임어택 랭킹 참가자 수 |

개인정보를 모으지 않는 원칙은 지킨다. 분석 SDK를 넣지 않고 위 네 군데에서만 본다.
랭킹 화면은 참가자 수를 보여 주므로 시대별 타임어택 랭킹이 그대로 "시대 N까지 간 사람 수" 퍼널이 된다.

## 2. 가설

- **H1 (이해)**: 쉬운 말 + 새 기능 소개 + 도움말을 넣으면, 친구 테스터 중 "뭐가 뭔지 모르겠다"고 답하는 비율이 절반 이하가 되고 70% 이상이 첫 세션에 시대 3에 간다.
- **H2 (재방문)**: 오프라인 보상 + 파견 복귀 알림이 있으면 D1이 40% 이상이다.
- **H3 (안내만으로 진행)**: 화면 안내('다음 할 일' 칩과 추천 줄)만 따라 해도 막힘 없이 시대 3에 간다. (자체 측정 가능: 아래 초보 봇)

숫자는 기준선이 없어서 정한 첫 목표다. 첫 측정 뒤 다시 맞춘다.

## 4. 에픽 → 피처 → 유저 스토리

**에픽 A. 처음 15분 안에 이해한다**
- 피처 A1 안내 따라가기
  - 스토리: 처음 하는 사람으로서, 나는 화면이 가리키는 것만 눌러도 앞으로 나가고 싶다. 왜냐하면 규칙을 읽고 싶지 않기 때문이다. (M)
  - 인수 조건: 초보 봇(안내 칩 + 추천 줄만 누름)이 15분 안에 시대 3 도달 / 안내 탭에 살 게 없는 '막힘' 시간이 전체의 20% 이하
- 피처 A2 창 줄이기
  - 스토리: 처음 하는 사람으로서, 나는 창이 연달아 떠서 흐름이 끊기지 않았으면 한다. 왜냐하면 무엇을 누르던 중인지 잊기 때문이다. (S)
  - 인수 조건: 첫 10분 창 10개 이하, 같은 창이 30초 안에 두 번 뜨지 않음

**에픽 B. 다음 날 다시 켠다**
- 피처 B1 돌아온 보상
  - 스토리: 바쁜 사람으로서, 나는 하루 뒤 켰을 때 쌓인 보상과 할 일을 바로 보고 싶다. 왜냐하면 짧게 하고 끄기 때문이다. (S)
  - 인수 조건: 오프라인 보상 창 → 다음 할 일 칩이 바로 보임

**에픽 C. 피드백을 모은다**
- 피처 C1 의견 보내기 (완료, 21차)
- 피처 C2 랭킹 참가자 수 (완료, 스프린트 1)
  - 스토리: 만든 사람으로서, 나는 시대별로 몇 명이 도달했는지 보고 싶다. 왜냐하면 어디서 그만두는지 알아야 고치기 때문이다. (S)
  - 인수 조건: 랭킹 화면에 '참가 N명', 모르면 표시 안 함
