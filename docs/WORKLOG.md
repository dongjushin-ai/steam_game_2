## 3. 번역 구조 (10:00 – 10:10)

- `src/i18n/index.ts`
  - `L("한국어", "English")`: UI 문구용. 두 언어뿐이라 사전 키 대신 원문과 번역을 나란히 둔다. 빠뜨린 곳은 "L( 밖의 한글" 검사로 잡는다.

  - 번역이 빠진 id는 `missing` 배열에 쌓인다 → 검수 스크립트에서 0건인지 확인.
- 번역표: `src/i18n/en/{eras,buildings,upgrades,events,codex,quiz,news,misc}.ts`, 전부 id 키. 퀴즈는 보기 순서가 정답 번호와 묶여 있어서 순서를 그대로 둔다.

- **연표**: 시대 이모지 대신 그 시대 AI 얼굴 썸네일.
- 같은 그림이 화면에 여러 장 뜨면 SVG 그라데이션 id가 겹쳐 다른 시대 색이 섞이므로, 복사본마다 id를 바꾸는 `uniqueIds()`를 거친다 (`src/ui/art.ts`). 도감·벤치 그림은 움직임을 끈 정지 그림.

## 26. 장면 효과

## 27. 성능: 애니메이션 150개 → 12개

새 효과를 넣고 재보니 CPU 4배 감속에서 서비스 탭이 **30fps**로 떨어짐 (p50 33ms, 긴 작업 12개).
하나씩 꺼 보며 원인을 찾음: 장면이 없으면 60fps, 배경 애니메이션만 끄면 60fps → **배경의 LED·진공관·별 애니메이션 약 150개**가 범인.
SVG 안 요소의 애니메이션은 GPU가 아니라 메인 스레드에서 돌아서, 개수만큼 매번 스타일 계산 비용이 든다.

1. 방을 세 층으로 분리: 정지한 방(한 번만 그림) / 움직이는 조각(별도 GPU 층) / 조명·비네트. 우주 장면은 별이 행성·태양 위에 찍히지 않게 거름.
   → 이것만으로는 그대로 30fps (그리기 비용이 아니라 애니메이션 개수 문제라서).
2. **같은 타이밍으로 깜박이는 요소를 `<g>` 하나로 묶어 애니메이션 하나로**. LED 타이밍을 지연 4종 × 주기 3종으로 양자화, 별도 지연 4종으로.
