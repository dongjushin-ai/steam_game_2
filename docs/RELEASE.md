## 2. 앱 빌드

웹 게임을 Capacitor로 감싼 안드로이드 앱이다 (`android/` 폴더).

| 항목 | 값 |
|---|---|
| targetSdk / compileSdk | 36 (Android 16). 2026-08-31부터 신규·업데이트 필수 |
| minSdk | 24 (Android 7.0) |
| 권한 | `INTERNET`, `POST_NOTIFICATIONS`(첫 파견 때 설명 후 요청), `RECEIVE_BOOT_COMPLETED`·`WAKE_LOCK`(재부팅 후 예약 알림 복구). `SCHEDULE_EXACT_ALARM`은 매니페스트에서 제거(정확한 알람 신고 불필요). 위치·카메라·저장소 없음 |
| 화면 | 세로 고정. 상태 표시줄 영역은 Capacitor가 넣는 `--safe-area-inset-*`로 피한다 |
| 뒤로 가기 | 창 닫기 → 첫 탭으로 → 저장 후 홈으로 내리기. 컷신 중에는 무시 |
| 서비스 워커 | 앱에서는 끈다 (파일이 이미 기기 안에 있음) |
| 공유 | 기록 카드 PNG를 앱 캐시에 쓰고 안드로이드 공유 창을 연다 |

로컬 빌드 (Android SDK 필요):
```
npm run android:sync          # 웹 빌드 → android/에 복사
cd android
./gradlew assembleDebug       # 친구 테스트용 APK: app/build/outputs/apk/debug/
./gradlew bundleRelease -PversionCode=2   # 업로드용 AAB (아래 서명 환경 변수 필요)
```

GitHub Actions: Actions 탭 → **Android build** → Run workflow (versionCode 입력).
디버그 APK는 항상, 서명된 AAB는 저장소 비밀값이 있을 때만 결과물로 올라온다.

**업로드할 때마다 versionCode를 1씩 올린다.** versionName(`1.0.0`)은 `android/app/build.gradle`.

## 3. 서명 (Play 앱 서명 + 업로드 키)

1. 업로드 키 만들기 (한 번):
   ```
   keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
2. 저장소 Settings → Secrets and variables → Actions에 넣기:
   - `ANDROID_KEYSTORE_BASE64`: `base64 -w0 upload.jks` 결과
   - `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`(`upload`), `ANDROID_KEY_PASSWORD`
3. 첫 AAB를 올릴 때 'Play 앱 서명'을 그대로 사용(구글이 배포 키 보관).
4. `upload.jks`는 **절대 커밋하지 않는다** (`.gitignore`에 `*.jks`, `*.keystore`).

### 플레이 게임즈 서비스 설정 (랭킹)
1. Play Console › 앱 › **플레이 게임즈 서비스 › 설정 및 관리 › 구성**에서 "이 게임은 Google API를 사용하지 않음"으로 새 게임 프로젝트를 만든다.
2. **사용자 인증 정보**: Android 사용자 인증 정보를 추가한다. 패키지 이름 `io.github.dongjushinai.aikiugi`. SHA-1은 둘 다 등록한다.
   - 업로드 키 SHA-1: `keytool -list -v -keystore upload.jks`
   - 앱 서명 키 SHA-1: Play Console › 설정 › 앱 서명
   - 디버그 APK로 시험하려면 디버그 키 SHA-1도 등록 (`~/.android/debug.keystore`)
3. 설정 화면의 **프로젝트 ID**(숫자)를 `android/app/src/main/res/values/strings.xml`의 `game_services_project_id`에 넣는다. 비어 있으면 랭킹이 꺼진 채로 동작한다.
4. **리더보드 15개**를 만들고, 받은 ID(`CgkI…`)를 `src/data/leaderboards.ts`의 `id`에 넣는다.

   | key | 이름 | 형식 | 정렬 | 점수 범위 제한(부정행위 방지) |
   |---|---|---|---|---|
   | overall | 종합 점수 | 숫자 | 높을수록 좋음 | 0 ~ 200,000 (무한 단계당 +300) |
   | feats | 업적 점수 | 숫자 | 높을수록 좋음 | 0 ~ 1,500 |
   | combo | 최고 콤보 | 숫자 | 높을수록 좋음 | 0 ~ 20,000 |
   | endless | 무한 단계 | 숫자 | 높을수록 좋음 | 0 ~ 500 |
   | ta0 ~ ta10 | 타임어택 1~11 | 시간(밀리초) | 낮을수록 좋음 | 최소값만: 사람형 봇 최고 기록의 절반쯤 (ta0 15초, ta1 30초, ta2 1분, ta3 2분, 이후 시대마다 +3분). 직접 해 본 기록이 시대 1 클리어 33초였으니 너무 빡빡하게 걸지 말 것 |

   - 점수는 기기에서 보내므로 조작할 수 있다. Console의 **변조 방지(점수 범위)**를 꼭 걸고, 이상한 기록은 Console에서 숨길 수 있다.
   - 기간별(오늘·이번 주·전체) 순위는 구글이 자동으로 따로 집계한다.
5. **테스터**: 출시 전에는 플레이 게임즈 설정의 '테스터'에 등록된 계정만 로그인된다. 비공개 테스트 친구들을 여기에도 넣는다.
6. 설정을 **게시**해야 실제로 켜진다 (앱 출시와 별개).

## 5. 심사에서 걸릴 만한 것과 처리

| 위험 | 정책 | 처리 |
|---|---|---|
| 실존 회사·제품 이름 | 지적 재산권, 사칭 | 사고파는 항목 이름은 일반 명칭으로 바꿈(GPU 모델명 → '텐서코어 GPU' 등, 커넥터 → '코드 저장소' 등). 실명은 역사 설명(도감·퀴즈·뉴스)에서 사실 서술로만. 로고 없음. 스토어 제목·설명·그림에 실명 없음. 게임 안 '정보'와 스토어 설명에 비제휴 고지 |
| 실존 인물 | 사칭 | 퀴즈·도감에서 공개된 사실만. 인물 평가·조롱 없음, 민감 사건 제외 원칙 유지 |
| 생성형 AI로 오해 | AI 생성 콘텐츠 정책 | 생성형 기능 없음. 설명 끝에 "챗봇이 아님" 명시 |

## 6. 출시 순서

1. GitHub Pages 게시(위 '만든 사람이 할 일' 1번) → `privacy.html` 열리는지 확인
2. 업로드 키 만들고 Actions 비밀값 등록
3. Play Console에서 앱 만들기 (기본 언어 한국어, 게임, 무료)
4. 4번 양식 전부 작성, `store/listing.md`대로 스토어 등록정보 입력
4-1. 플레이 게임즈 서비스 설정(위), 리더보드 ID·프로젝트 ID를 코드에 넣고 커밋
5. Actions → Android build (versionCode 1) → AAB 받기
6. 테스트 → 비공개 테스트 트랙에 AAB 업로드, 테스터 12명 이상 등록, 심사 제출
7. 14일 동안 테스트 (피드백 반영 업데이트는 versionCode 2, 3…)
   - 테스트 전에 `src/ui/feedback.ts`의 `FEEDBACK_FORM`(구글 폼 주소, 추천) 또는 `FEEDBACK_EMAIL`을 채운다. 비워 두면 '의견 보내기'는 글을 복사하거나 공유 창을 열어 테스터가 직접 보내게 한다
8. 프로덕션 액세스 신청 → 승인 후 프로덕션 출시 (국가: 대한민국부터, 원하면 전 세계)

## 7. 출시 전 기기 점검

- [ ] 첫 실행: 시작 화면 → 튜토리얼 → 첫 업그레이드
- [ ] 홈 버튼으로 나갔다 들어오기: 오프라인 보상, 음악 일시정지·재개
- [ ] 뒤로 가기: 창 닫힘 → 첫 탭 → 홈으로 (게임이 꺼지지 않고 저장됨)
- [ ] 앱 완전 종료 후 재실행: 진행 상황 유지
- [ ] 상태 표시줄·내비게이션 바가 숫자·탭을 가리지 않음 (제스처 내비/3버튼 둘 다)
- [ ] 기록 카드 → 공유·저장 → 갤러리 저장, 메신저 전송
- [ ] '정보'의 개인정보처리방침 링크가 브라우저로 열림
- [ ] 비행기 모드에서 플레이
- [ ] 랭킹: 첫 실행 자동 로그인(또는 로그인 버튼) → 보스 깨고 랭킹 화면에 내 점수 → 오늘/이번 주/전체 전환 → 칭호 달기
- [ ] 플레이 게임즈 로그인을 거절해도 게임이 정상 동작
- [ ] 진동: 탭·구매는 가볍게, 보스 승리는 성공 패턴, 설정에서 끄면 멈춤
- [ ] 의견 보내기: 글 적고 보내기 → 폼/메일/공유 창이 열림
- [ ] 첫 파견 → 알림 설명 창 → 시스템 권한 → 앱을 내린 뒤 파견 복귀 알림이 옴 (몇 분 늦을 수 있음), 앱에 돌아오면 남은 예약이 지워짐
- [ ] 설정 › 세이브 파일로 저장 → 공유 창에서 드라이브에 저장 → 앱 삭제·재설치 → 세이브 파일 불러오기로 복원
- [ ] 엔딩 뒤 벤치마크 탭 '특이점 너머' → 단계 도전·승리·영구 보너스, 랭킹 '무한' 탭
- [ ] 다크 모드, 큰 글꼴 설정
