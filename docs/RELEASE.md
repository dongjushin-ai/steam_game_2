## 1. 개발자 계정

- Play Console 가입(1회 등록비 25달러), 신원 확인.
- **개인 계정**(2023-11-13 이후 생성)은 프로덕션 출시 전에 **비공개 테스트: 테스터 12명 이상이 14일 연속 참여**해야 한다. 조직 계정(D-U-N-S 필요)은 면제.
  - 친구 12명 이상의 구글 계정 이메일을 모아 테스터 목록에 넣는다. 14일 동안 앱을 지우지 않고 가끔 열어 보게 부탁한다.
  - 14일 뒤 Console의 '프로덕션 액세스 신청'에서 테스트 내용을 묻는 질문에 답한다 (무엇을 고쳤는지 적을 수 있게 피드백을 기록해 둔다).

## 2. 앱 빌드

웹 게임을 Capacitor로 감싼 안드로이드 앱이다 (`android/` 폴더).

| 항목 | 값 |
|---|---|
| targetSdk / compileSdk | 36 (Android 16). 2026-08-31부터 신규·업데이트 필수 |
| minSdk | 24 (Android 7.0) |
| 권한 | `INTERNET`만 (Capacitor 기본). 위치·카메라·저장소·알림 권한 없음 |
| 화면 | 세로 고정. 상태 표시줄 영역은 Capacitor가 넣는 `--safe-area-inset-*`로 피한다 |
| 뒤로 가기 | 창 닫기 → 첫 탭으로 → 저장 후 홈으로 내리기. 컷신 중에는 무시 |
| 서비스 워커 | 앱에서는 끈다 (파일이 이미 기기 안에 있음) |
| 공유 | 기록 카드 PNG를 앱 캐시에 쓰고 안드로이드 공유 창을 연다 |

로컬 빌드 (Android SDK 필요):
```
npm run android:sync          # 웹 빌드 → android/에 복사
cd android
./gradlew assembleDebug       # 친구 테스트용 APK: app/build/outputs/apk/debug/
./gradlew bundleRelease -PversionCode=2   # 업로드용 AAB (아래 서명 환경 변수 필요)
```

GitHub Actions: Actions 탭 → **Android build** → Run workflow (versionCode 입력).
디버그 APK는 항상, 서명된 AAB는 저장소 비밀값이 있을 때만 결과물로 올라온다.

**업로드할 때마다 versionCode를 1씩 올린다.** versionName(`1.0.0`)은 `android/app/build.gradle`.

## 3. 서명 (Play 앱 서명 + 업로드 키)

1. 업로드 키 만들기 (한 번):
   ```
   keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
2. 저장소 Settings → Secrets and variables → Actions에 넣기:
   - `ANDROID_KEYSTORE_BASE64`: `base64 -w0 upload.jks` 결과
   - `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`(`upload`), `ANDROID_KEY_PASSWORD`
3. 첫 AAB를 올릴 때 'Play 앱 서명'을 그대로 사용(구글이 배포 키 보관).
4. `upload.jks`는 **절대 커밋하지 않는다** (`.gitignore`에 `*.jks`, `*.keystore`).

## 6. 출시 순서

1. 이 브랜치를 main에 머지 → GitHub Pages에 `privacy.html` 게시 확인
2. 업로드 키 만들고 Actions 비밀값 등록
3. Play Console에서 앱 만들기 (기본 언어 한국어, 게임, 무료)
4. 4번 양식 전부 작성, `store/listing.md`대로 스토어 등록정보 입력
5. Actions → Android build (versionCode 1) → AAB 받기
6. 테스트 → 비공개 테스트 트랙에 AAB 업로드, 테스터 12명 이상 등록, 심사 제출
7. 14일 동안 테스트 (피드백 반영 업데이트는 versionCode 2, 3…)
8. 프로덕션 액세스 신청 → 승인 후 프로덕션 출시 (국가: 대한민국부터, 원하면 전 세계)
