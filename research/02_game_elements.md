# 02. 게임 요소 사전 — 키우기(Idle) 시스템 재료

> "사냥" 대신 **사람들의 질문에 답변**해서 돈을 번다.
> 아래는 업그레이드 트리·스탯·재화로 쓸 수 있는 실제 AI 개념들과 참고 수치다.
> 수치는 밸런싱용 "느낌"을 잡는 레퍼런스이며, 게임 안에서는 단순화·과장한다.

---

## 1. 핵심 루프

```
 질문 도착(💬) ──▶ AI가 답변(토큰 소모 🔤) ──▶ 보상(💵) − 추론 비용(⚡/💸)
       ▲                                              │
       └──── 업그레이드(🧠 모델 · 🖥️ 컴퓨트 · 🏢 데이터센터 · 🔌 커넥터) ◀──┘
```

- **순이익 = 답변 보상 × 품질 − 토큰 수 × 토큰 단가** → "토큰 가성비"가 곧 게임의 중심 지표.
- **할루시네이션 확률** → 실패 시 보상 0 + 평판 하락(환불).
- **방치형**: 오프라인 동안 쌓인 질문을 자동 처리(오프라인 수익). 2026 "Dreaming" 오마주로 오프라인 보상 압축 업그레이드.

## 2. 재화

| 아이콘 | 재화 | 획득 | 용도 |
|---|---|---|---|
| 💵 | 크레딧 | 답변 보상 | 대부분의 업그레이드 |
| 🔤 | 토큰 | 소모 자원(초당 처리량) | 답변 생성 |
| 📊 | 데이터 | 크롤링·라이선스·합성데이터 | 학습(모델 세대 업) |
| 🧠 | 연구 포인트 | 연구자·논문 | 연구 트리(아키텍처/기법) |
| ⚡ | 전력(MW→GW) | 발전소·계약 | 데이터센터 가동 한도 |
| ⭐ | 평판/사용자 수 | 정답·바이럴 | 질문 유입량 배수 |
| 💾 | 체크포인트(프레스티지) | 새 모델 출시/AI 겨울 리셋 | 영구 버프 |

## 3. 스탯

| 스탯 | 실제 개념 | 효과 |
|---|---|---|
| 지능(IQ) | 파라미터 수, 스케일링 법칙 | 어려운 질문 처리 가능, 보상 ↑ |
| 속도(tok/s) | 추론 처리량, 투기적 디코딩 | 초당 답변 수 |
| 컨텍스트 창 | 2K → 4K → 8K → 32K → 100K → 200K → **1M**(2026 표준) → 10M(팬픽) | 긴 질문(문서 요약, 레포 전체 리팩토링) 해금 |
| 최대 출력 | 4K → 128K(2026) | 긴 답변 보상 |
| 정확도 | 할루시네이션율, RLHF, RAG | 실패 확률 ↓ |
| 토큰 단가 | $/MTok, 양자화, 캐싱 | 비용 ↓ |
| 안전성 | 탈옥/프롬프트 인젝션 방어, 정렬 | 악성 질문 이벤트 방어, 규제 이벤트 완화 |
| 메모리 | LSTM → KV 캐시 → 장기 메모리 → Dreaming | 단골 유저 보너스, 오프라인 효율 |

## 4. 업그레이드 트리

### 4-1. 🖥️ 컴퓨트 (하드웨어)
`진공관 → 트랜지스터 → LISP 머신 → 워크스테이션 CPU → 게이밍 GPU ×2(AlexNet, GTX 580) → K80 → V100 → A100 → H100(HBM3 80GB, 3TB/s) → H200(HBM3e 141GB) → B200/GB200 NVL72 → GB300 → Rubin(HBM4) → (팬픽) 광자 칩 → 양자 가속기`
- 사이드 브랜치: **TPU**(구글), **Cerebras 웨이퍼 칩**, **Groq LPU**(초고속 추론) — "칩 다변화" 업그레이드
- 🎮 이벤트: GPU 품귀(가격 ×2), 수출 규제(일부 칩 구매 불가), 딥시크 쇼크(가격 폭락)

### 4-2. 💾 메모리
`RAM → VRAM → HBM2 → HBM3 → HBM3e → HBM4 → HBM4E(16단, 2026 계획)`
- 기법 노드: KV 캐시, PagedAttention, **FlashAttention**, 컨텍스트 압축, 프롬프트 캐싱
- 장기 기억: LSTM → RAG/벡터 DB → 메모리 기능 → "Dreaming"(세션 간 메모리 정리)

### 4-4. 🧠 아키텍처 (연구 트리, 시대별 해금)
`규칙 기반 → 퍼셉트론 → MLP+역전파 → CNN → RNN/LSTM → seq2seq+어텐션 → Transformer → MoE → 추론 모델(테스트 타임 컴퓨트) → 하이브리드 추론 → 에이전트 → (팬픽) 월드 모델(JEPA 오마주)`

### 4-5. 🎓 학습 기법
지도학습, 비지도, 강화학습, 자가대국(AlphaZero), 전이학습, 파인튜닝, **LoRA**, **RLHF**, **Constitutional AI**, DPO, 지식 **증류**, **합성 데이터**, 커리큘럼 학습

### 4-6. 💸 토큰 가성비 (추론 최적화)
| 업그레이드 | 실제 개념 | 효과(예) |
|---|---|---|
| 양자화 INT8 → INT4 → FP4 | Quantization, llama.cpp | 비용 −25%씩, 정확도 −소량 |
| 프롬프트 캐싱 | 캐시 읽기 = 입력가의 ~10% | 반복 질문 비용 −90% |
| 배치 API | 비동기 일괄 처리 ~50% 할인 | 느린 대신 반값 |
| MoE | 활성 파라미터만 계산 | 비용 −40% |
| 투기적 디코딩 | 작은 모델이 초안 | 속도 ×2 |
| 증류 | 큰 모델 → 작은 모델 | "Haiku형" 저가 유닛 해금 |
| 모델 라우터 | 쉬운 질문은 작은 모델로 | 자동 최적화 (GPT-5 라우터 사고 이벤트 연동) |
| 적응형 사고(effort) | low/medium/high/max | 질문 난이도별 토큰 사용량 조절 |

### 4-7. 🔌 도구 · 플러그인 · 커넥터 (생태계)
- **플러그인 슬롯**(2023 ChatGPT 플러그인 오마주): 웹 검색, 코드 인터프리터, 계산기, 이미지 생성
- **Function calling / Tool use** → 슬롯 수 증가
- **MCP 커넥터**(2024.11~): GitHub, Slack, Google Drive, Notion, Gmail, 캘린더, DB, Figma … → 각 커넥터가 특정 질문 카테고리 보상 배수
- **Computer Use / 브라우저 에이전트** → 자동 처리 유닛
- **Skills, 서브에이전트, Hooks, 샌드박스, Artifacts** → 개발자 트리
- **에이전트 팀**: 병렬 처리 유닛(멀티 에이전트)

### 4-8. 🧑‍💻 개발자(Dev) 트리
`자동완성 → Copilot(2021) → 채팅 IDE → CLI 에이전트(Claude Code, 2025) → 바이브 코딩 → PR 리뷰 봇 → CI 자동 수정 → 클라우드 백그라운드 에이전트 → 자율 소프트웨어 팀`
- 개발자 유저층은 질문당 보상이 가장 높지만 정확도 요구도 높음.

### 4-9. 🛡️ 안전 · 정렬
할루시네이션 감소, 탈옥 방어, 프롬프트 인젝션 방어, 레드팀, 해석가능성(Mechanistic Interpretability), 모델 카드, 책임있는 확장 정책
- 효과: 규제 이벤트 피해 감소, 기업 고객(B2B) 질문 해금, 평판 ↑

### 4-10. 👥 인력(유닛)
대학원생 → 포닥 → ML 엔지니어 → 10x 엔지니어 → 프롬프트 엔지니어(2023 밈) → 레드팀 → 수석 과학자 → 노벨상 수상자(2024 힌튼·허사비스 오마주)
- 실존 인물은 도감(학습용)에만 실명, 고용 유닛은 가상의 캐릭터로.
