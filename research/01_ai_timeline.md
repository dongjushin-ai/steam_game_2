## Era 0. 프롤로그: 자동인형과 계산기 (고대 ~ 1940년대) — 튜토리얼

| 연도 | 사건 | 🎮 활용 |
|---|---|---|
| 고대 | 탈로스·갈라테아 신화, 헤론의 자동 극장 | 오프닝 컷신 "인간은 늘 생각하는 기계를 꿈꿨다" |
| 9세기 | 알콰리즈미 → "알고리즘" 어원 | 첫 업그레이드 이름: `알고리즘 Lv.1` |
| 1843 | 에이다 러브레이스의 해석기관 노트 | 도감 카드 |
| 1943 | McCulloch–Pitts 인공 뉴런 | 첫 유닛 "뉴런 1개" (클릭 1회 = 질문 1개 답변) |
| 1950 | 튜링 「계산 기계와 지능」, 튜링 테스트 | **첫 보스(벤치마크)**: 튜링 테스트 |

## Era 1. 기호주의의 탄생 (1950 ~ 1956)

| 연도 | 사건 | 🎮 활용 |
|---|---|---|
| 1951 | SNARC (민스키, 최초의 신경망 기계) | 하드웨어 트리 시작점 |
| 1955–56 | Logic Theorist (뉴얼·사이먼) — 최초의 AI 프로그램 | 연구 해금: "정리 증명" |
| 1956 | **다트머스 워크숍** — "Artificial Intelligence" 용어 탄생 | Era 클리어 컷신, 칭호 "AI의 탄생" |

## Era 2. 황금기 (1956 ~ 1974)

| 연도 | 사건 | 🎮 활용 |
|---|---|---|
| 1957 | General Problem Solver | 연구 노드 |
| 1958 | 로젠블랫 **퍼셉트론** / McCarthy의 LISP | 아키텍처 트리 1단계 / 언어 업그레이드 |
| 1966 | **ELIZA** (최초의 챗봇, 정신과 의사 흉내) | 이 시대의 "내 AI" 외형. 질문에 "그게 왜 궁금하신가요?"로만 답함(밈) |
| 1966–72 | Shakey 로봇 | 도감 |
| 1968–70 | SHRDLU (블록 월드) | 미니 질문 "빨간 블록을 초록 블록 위에" |
| 1969 | 민스키·패퍼트 『퍼셉트론』 — XOR 문제 | **디버프 이벤트**: 신경망 연구 효율 −50% |

### ❄️ 1차 AI 겨울 (1974 ~ 1980)
- 1973 라이트힐 보고서 → 영국 AI 예산 삭감, DARPA 축소.
- 🎮 **프레스티지(환생) 장치 #1**: "AI 겨울이 왔다" — 자금 수입 급감. 버티거나, 리셋하고 "겨울 생존 보너스"를 받는다.

## Era 3. 전문가 시스템 붐 (1980 ~ 1987)

| 연도 | 사건 | 🎮 활용 |
|---|---|---|
| 1970s | MYCIN (의료 진단 규칙 ~600개) | 질문 카테고리 "의료" 해금 |
| 1980 | XCON (DEC, 연간 수천만 달러 절감) | 첫 **B2B 계약** — 패시브 수입 |
| 1982 | 일본 5세대 컴퓨터 프로젝트 | 라이벌 국가 이벤트 |
| 1984 | Cyc (상식 지식베이스, 지금도 진행 중) | "규칙 1만 개 입력" 노가다 업그레이드 (밈) |
| 1980s | LISP 머신 | 하드웨어 2단계 |
| 1982 | 홉필드 네트워크 / 1985 볼츠만 머신 | 연구 노드 (2024 노벨 물리학상 이스터에그) |
| 1986 | **역전파** 대중화 (Rumelhart·Hinton·Williams) | 아키텍처: 다층 퍼셉트론 해금, XOR 디버프 해제 |

### ❄️ 2차 AI 겨울 (1987 ~ 1993)
- LISP 머신 시장 붕괴, 전문가 시스템 유지비 폭증.
- 🎮 "LISP 머신 재고 처분" 이벤트: 하드웨어 일부 가치 하락.

## Era 5. 딥러닝 혁명 (2006 ~ 2016)

| 연도 | 사건 | 🎮 활용 |
|---|---|---|
| 2006 | 힌튼 "Deep Belief Network" — 딥러닝 부활 | Era 시작 컷신 |
| 2007 | **CUDA** 공개 | 하드웨어: GPU 해금 (게임용 GPU → 연구용) |
| 2009 | **ImageNet** (1400만 장) | 데이터 트리 핵심 |
| 2011 | IBM Watson 제퍼디! 우승 / Siri 출시 | 보스: 퀴즈쇼 / 모바일 비서 유닛 |
| 2012 | **AlexNet** (GTX 580 두 장) | 하드웨어: "게이밍 GPU 2장" 업그레이드, 정확도 대폭 상승 |
| 2012 | 구글 브레인 "고양이 뉴런" (16,000 CPU) | 이스터에그 질문 "이거 고양이야?" |
| 2013 | **word2vec** — 왕 − 남자 + 여자 = 여왕 | 임베딩 업그레이드 |
| 2014 | **GAN** / seq2seq / 어텐션(Bahdanau) | 이미지 생성 사이드 트리 |
| 2013–15 | DQN 아타리 | RL 트리 |
| 2015 | TensorFlow 공개, OpenAI 설립 | 프레임워크 업그레이드 |
| 2016 | **알파고 vs 이세돌 (4:1)**, 37수 / 78수 | 보스: 바둑. 78수 = "신의 한 수" 크리티컬 이벤트 (존중하는 톤) |
| 2016 | PyTorch 공개 | 프레임워크 업그레이드 |
| 2016 | MS Tay (16시간 만에 중단) | 안전성 교훈 이벤트(가볍게): "인터넷에서 그냥 배우면 안 된다" — 데이터 필터 업그레이드 해금 |

| 연도 | 사건 | 🎮 활용 |
