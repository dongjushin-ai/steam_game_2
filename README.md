# 🤖 AI 키우기 — *Attention Is All You Idle*

> 1943년의 인공 뉴런 하나에서 2026년 프런티어 에이전트, 그리고 그 너머까지.
> **사냥 대신 사람들의 질문에 답하며** AI를 키우는 모바일 세로형 방치형 게임.

AI 역사 80년(+고대 신화)을 11개 시대로 압축했다. 튜링 테스트, ELIZA, 두 번의 AI 겨울, 딥블루, AlexNet, 알파고, 트랜스포머, ChatGPT, MCP, 바이브 코딩, 그리고 2026년 Claude 5 패밀리까지. AI를 아는 사람이라면 곳곳에서 웃을 수 있는 팬메이드 게임이다.

🌐 **한국어 / English** — 첫 실행 때 브라우저 언어로 자동 선택, 도감 → 설정에서 바꿀 수 있다. (English title: *Grow Your AI*)

## 플레이

```bash
npm install
npm run dev        # http://localhost:5173
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트 후 GitHub Pages에 배포한다.
(최초 1회: 저장소 **Settings → Pages → Source: GitHub Actions**)
홈 화면에 추가하면 PWA로 설치되어 오프라인에서도 돌아간다.

## 개발

```bash
npm test            # 데이터 검사 + 번역 검사 + 핵심 로직 테스트 + 봇 전체 플레이 시뮬레이션
npm run sim         # 봇이 처음부터 엔딩까지 플레이 (30분마다 로그)
npm run calibrate   # 시대별 비용·보스 체력 자동 보정 → src/data/balance.ts
npm run playtest    # 사람처럼 플레이하는 봇 5회 → 시대별 체류 시간·정체 구간
npm run build
npm run build:single  # 파일 하나짜리 dist/ai-kiugi.html (친구에게 보내기용, 더블클릭으로 실행)
```

```
src/
  core/      게임 로직 (DOM 없음 — 시뮬레이터가 그대로 import)
  data/      콘텐츠: 시대·건물·업그레이드·티어·이벤트·도감 + 밸런스 배수
  ui/        화면 (바닐라 TS + DOM, 프레임워크 없음)
  i18n/      언어 전환: L("한국어", "English") + 영어 번역표(en/*.ts, id 키)
scripts/     시뮬레이션 봇, 보정, 테스트
research/    Obscura로 수집한 AI 역사 자료 195건과 정리 문서
docs/GDD.md  수식과 시스템 설계
```

### 콘텐츠 추가하기
새 사건이나 모델은 `src/data/*.ts`에 한 항목을 추가하고, 같은 id로 `src/i18n/en/*.ts`에 영어를 넣는다 (빠뜨리면 `npm test`가 알려준다). `npm test`가 id 중복, 선행 연구, 시대 범위, 보스 요구치 달성 가능 여부를 검사하고, 봇이 엔딩까지 도달하는지 확인한다. 비용 곡선이 크게 바뀌면 `npm run calibrate`.

## 밸런스

| 플레이 방식 | 엔딩 도달 |
|---|---|
| 최적 봇 (초당 1탭, VIP 질문 안 잡음) | 약 1시간 44분 |
| 사람형 봇 (`npm run playtest`, 5회 중앙값) | 약 2시간 4분 (5/5 엔딩, 40분 넘는 정체 0) |

사람형 봇은 4초마다 판단하고, 40%는 최적이 아닌 것을 사며, 처음 15분 뒤엔 탭을 덜 하고, VIP 질문 60%·퀴즈 60%·탈옥 70%만 잡고, 파견은 가끔 잊는다. 실제 사람은 쉬엄쉬엄 하므로 3~4시간 정도를 예상한다. 새 모델 출시는 막힐 때 쓰는 가속 수단이고, 쓰지 않아도 엔딩을 볼 수 있다.

## 고지
비상업 팬메이드 게임이다. 실존 기업·제품·인물의 이름은 도감의 역사 설명에만 쓰고, 게임 속 수치와 이벤트 효과는 재미를 위해 단순화·과장했다. 민감한 실제 사건(사망·총기·딥페이크·혐오 발언·군사 분쟁 등)은 의도적으로 넣지 않았다 ([목록](research/03_events.md)).
